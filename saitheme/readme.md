# SaiTheme

Tema WordPress sederhana untuk website personal milik Saif.

Tema ini dibuat sebagai bagian dari proses belajar membuat website,
khususnya dalam mempelajari HTML, CSS, PHP, dan WordPress.

## Tentang Project

SaiTheme adalah tema WordPress dengan konsep:

- Clean
- Minimal
- Modern
- Responsive
- Putih, abu-abu, dan biru

Website ini digunakan sebagai personal website untuk memperkenalkan
diri, menampilkan project yang pernah dikerjakan, dan menjadi tempat
untuk mendokumentasikan proses belajar web development.

## Tujuan

Project ini dibuat untuk:

- Belajar membuat tema WordPress dari awal
- Memahami struktur tema WordPress
- Belajar menggunakan PHP dalam WordPress
- Belajar membuat tampilan website dengan HTML dan CSS
- Mencoba membuat website responsive
- Menampilkan project dan proses belajar dalam sebuah website personal

## Teknologi

Teknologi yang digunakan:

- HTML
- CSS
- PHP
- WordPress
- VS Code
