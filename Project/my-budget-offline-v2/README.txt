BUDGET SAYA - VERSI OFFLINE

Tujuan
- Dipakai sehari-hari di HP tanpa internet.
- Data disimpan lokal menggunakan IndexedDB.
- Tidak membutuhkan Laragon, PHP, MySQL, hosting, atau server.

Fitur
- Banyak Plan terpisah.
- Saldo awal dan periode bebas.
- Budget bulanan otomatis.
- Uang masuk/keluar.
- Cadangan dan alokasi.
- Arsip/pulihkan Plan.
- Export/Import backup JSON.
- PWA/offline service worker.

Catatan penting
- Versi ini menyimpan data di perangkat/browser.
- Data tidak otomatis sinkron dengan versi laptop PHP/MySQL.
- Backup rutin dianjurkan sebelum menghapus data atau berpindah perangkat.
- Untuk instalasi sebagai PWA, browser biasanya memerlukan secure context (HTTPS atau lingkungan yang dianggap aman). Jika dipaketkan menjadi APK nanti, data tetap dapat offline.

Pengembangan berikutnya
- Paket APK Android dari aset offline ini.
- Validasi dan UX tambahan setelah pengujian pengguna.
